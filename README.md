# 乐事咔嚓接得住

一个 40 秒轻量接物反应小游戏：左右移动乐事薯片罐，接住金黄薯片与口味道具，避开受潮软片。

## 在线体验

- Cloudflare Pages：https://lays-crunch-catch.pages.dev/
- GitHub Pages：https://lau123105.github.io/lays-crunch-catch/

## 玩法

- 手机左右滑动，电脑使用 `←` / `→` 或 `A` / `D`
- 薯片 +1 分，口味道具 +3 分，受潮软片 -1 条命
- 每接住 10 片薯片触发「咔嚓！脆得刚刚好」彩蛋
- 40 秒或 3 条生命耗尽后结算奖励

## 本地运行

直接用浏览器打开 `index.html`，或在本目录执行：

```bash
python3 -m http.server 8765
```
